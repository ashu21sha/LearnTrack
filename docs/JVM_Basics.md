JDK:- It is a java development kit.It is mainly used to develop the Java applications.
It includes JRE and other development tools like javac,javadoc etc.

JRE:- It is Java runtime environment It mainly contains JVM and other Java Libraries. If we want to run
a java application then JRE is needed.

JVM:- It is a java Virtual Machine. It converts bytecodes(.class file) to Machine level Language.

Byte code:- Bytecode is the intermediate code generated by the Java compiler (javac) after compiling a .java file.
It is stored in a .class file and is executed by the JVM.

Java follows “Write Once, Run Anywhere” because Java code is compiled into platform-independent bytecode.
The same .class file can run on Windows, Linux, or macOS the only thing needed is JVM.
